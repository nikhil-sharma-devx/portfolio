# Nikhil Sharma — Portfolio Website

A modern, responsive portfolio website built with **React + Vite**, featuring a sleek dark theme with glassmorphism effects and smooth scroll animations.

🔗 **Live:** _Coming soon_

---

## ✨ Features

- **Fully Responsive** — Looks great on desktop, tablet, and mobile
- **Dark Theme** — Premium dark UI with purple/blue gradient accents
- **Smooth Animations** — Scroll-triggered reveal animations throughout
- **Glass Morphism** — Frosted glass navbar and card effects
- **SEO Optimized** — Proper meta tags, semantic HTML, and heading hierarchy
- **Modular Components** — Clean, reusable React component architecture

## 📂 Sections

| Section          | Description                                      |
| ---------------- | ------------------------------------------------ |
| **Hero**         | Intro with stats and call-to-action buttons      |
| **About**        | Bio and quick-info cards                         |

## 🛠 Tech Stack

- **React 19** — UI framework
- **Vite** — Build tool & dev server
- **React Icons** — Icon library (Feather icons)
- **Vanilla CSS** — Custom design system with CSS variables

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm

### Install & Run

```bash
# Clone the repo
git clone https://github.com/nikhil-sharma-devx/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```

Output will be in the `dist/` folder, ready to deploy.

## 🌐 Deployment

This site can be hosted for free on any of these platforms:

| Platform             | Command / Steps                                       |
| -------------------- | ----------------------------------------------------- |
| **Vercel**           | `npx vercel` or connect GitHub repo                   |
| **Netlify**          | Drag & drop `dist/` folder, or connect GitHub         |
| **GitHub Pages**     | Use `vite-plugin-gh-pages` or deploy `dist/` manually |
| **Cloudflare Pages** | Connect GitHub repo, build command: `npm run build`   |
